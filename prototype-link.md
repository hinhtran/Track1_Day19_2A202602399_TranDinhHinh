# Prototype Link

Nhóm mình đã code trực tiếp Prototype thành một trang web (HTML) thay vì dùng Figma. 
File prototype đã được đính kèm trong thư mục này với tên: `prototype.html`.

Chỉ cần click đúp vào file `prototype.html` để mở bằng trình duyệt (Chrome/Edge) và trải nghiệm cả 3 Option.

- Ở trên cùng có thanh Menu để chuyển đổi (Reset) qua lại giữa Option A, B và C.
- Prototype này đáp ứng đủ yêu cầu: 70% Common Context (Màn hình Video Vlearn), và thể hiện rất rõ sự phân chia công việc giữa User - AI ở 3 cơ chế.
